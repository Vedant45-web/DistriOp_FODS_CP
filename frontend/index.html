DistriOpt Placement Heuristic

Mathematical formulation implemented in C++
Score(N, J) = 0.30·CPU_free + 0.30·RAM_free + 0.20·GPU_free + 0.10·CPU_fit + 0.10·RAM_fit
1
Feasibility Filter

Nodes without sufficient free CPU, RAM, and GPU capacity are immediately disqualified.

2
Availability Evaluation (80%)

Balances cluster load by preferring machines with available CPU, RAM, and GPU headroom.

3
Tightness Fit (20%)

Prevents over-allocation by reserving larger machines for heavier upcoming jobs.

ACADEMIC FOUNDATIONS

FoDS Data Structures & Algorithms Lab

Interactive reference and live testing suite for the custom data structures and algorithms implemented in include/fods.hpp.

FIFO

FODSQueue<T>

Linked-list backed FIFO queue. Used in DistriOpt for FCFS Scheduling.

Enqueue: O(1) · Dequeue: O(1)
HEAP

FODSPriorityQueue<T>

Array-backed Binary Max-Heap. Used in DistriOpt for Priority-based Scheduling.

Insert: O(log n) · ExtractMax: O(log n)
LINKED

FODSLinkedList<T>

Singly linked list with dynamic node chaining. Powers the Cluster Node Registry.

Insert: O(1) · Search: O(n) · Delete: O(n)
ARRAY

FODSArray<T>

Contiguous dynamic array with 2x geometric growth. Used for internal metric buffers.

Access: O(1) · Amortized Push: O(1)

Security & Hardware Telemetry Specifications

Worker capabilities and fail-safe architecture
CPU & RAM Hardware Detection

Uses Windows GetSystemInfo and GlobalMemoryStatusEx to detect physical cores and memory automatically.

NVIDIA GPU Telemetry

Queries nvidia-smi for GPU model and VRAM. (Live jobs execute on CPU; GPU telemetry is recorded).

Watchdog Heartbeat & Recovery

Every 3 seconds, a background watchdog thread checks workers. If no heartbeat arrives for 15s, work is requeued.

Allow-Listed Secure Workloads

Zero arbitrary shell commands. Agents execute only vetted matrix multiplications, neural inference, and sorting passes.
